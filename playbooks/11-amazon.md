# Amazon 商品与广告评估｜零基础一步步操作

> 在实际卖家资格确认后，结合商品真实性、平台费用、库存、竞争与广告基础经济性。

## 先准备什么

- 建立一个项目文件夹，内含本章原始证据、输入假设、已完成表格、截图和下一步决策。
- 在任何付费工具和投流前，记录最坏可承受损失与验证资金上限。
- 对真实规则、平台展示、实际订单和教学假设使用不同标签，不混淆来源。

## 操作清单（按先后执行）

### 13-01 创建卖家资料并验证

**目标：** 按Amazon官方注册流程操作  
**预计耗时：** 25 分钟 · **优先级：** 进阶

**照着操作：**

- 1. 打开Amazon美国站完整演练，对照真实主体资料、类目条件和官方费用入口。
- 2. 使用真实企业材料，通过身份验证及税务访谈，选合适销售计划
- 3. 将结果填写到「examples/amazon-home.md」或对应记录表，并按“账号核验通过记录”逐项验收；每一条外部事实附原始网址/沟通记录，未知项保留待核查。

**可用资料：** [打开模板/入口](../examples/amazon-home.md) · [详细操作](../playbooks/11-amazon.md)

**完成标准：** 账号核验通过记录

**卡住怎么办：** 失败走官方审核与申诉，拒绝黑灰号

**证据性质：** 可复现的操作建议（非平台政策）。记录原始来源，不将教学演练当作成交证明。

## 一次完整验证如何留证据

| 字段 | 应填写内容 |
|---|---|
| 本次要判断的问题 | 一句话，能作出 Go / Pivot / Stop 决定 |
| 目标客户和市场 | 国家、细分人群、购买场景 |
| 原始证据 | 客户回复、报价、订单或官方规则原文 |
| 假设成本 | 逐项列出，不能当作供应商报价 |
| 实际成本 | 结算截图/账单，有日期与币种 |
| AI 做了什么 | 输入、提示词、输出、人工复核点 |
| 结果与下一次动作 | 继续 / 调整 / 暂停，负责人和截止时间 |

## 常见失败与处理

**没有支付资格：** 换可用的合规平台或服务路径，不购买非正规账号。  
**看到热门商品：** 先证明自己能以合理成本获取客户，而不是先囤货。  
**利润为正但现金不够：** 缩小样品/试单规模，记录首批资金与到账周期。  
**AI 输出与商品不符：** 删除不实宣传、重新核对供应商文件和样品。  
**样本太小：** 保留未知，不把一次接单外推成稳定增长。
