# SKU 决策与候选排序｜零基础一步步操作

> 对采购价、配送、广告、退款率、差异化、库存和质量风险分别打分；选择不超过三个低成本测试 SKU。

## 先准备什么

- 建立一个项目文件夹，内含本章原始证据、输入假设、已完成表格、截图和下一步决策。
- 在任何付费工具和投流前，记录最坏可承受损失与验证资金上限。
- 对真实规则、平台展示、实际订单和教学假设使用不同标签，不混淆来源。

## 操作清单（按先后执行）

### 05-01 建立20个候选

**目标：** 宽进严出  
**预计耗时：** 25 分钟 · **优先级：** 必须

**照着操作：**

- 1. 拿第3至4章的需求和竞品表做输入，不用AI凭空填写销量或需求。
- 2. 从公开搜索、需求卡与供应链能力列20个候选，去除侵权和高监管品类
- 3. 将结果填写到「templates/market-research.csv」或对应记录表，并按“候选商品表20行”逐项验收；每一条外部事实附原始网址/沟通记录，未知项保留待核查。

**可用资料：** [打开模板/入口](../templates/market-research.csv) · [详细操作](../playbooks/03-sku-score.md)

**完成标准：** 候选商品表20行

**卡住怎么办：** 缺素材就从目标用户同一场景扩展

**证据性质：** 可复现的操作建议（非平台政策）。记录原始来源，不将教学演练当作成交证明。

### 05-02 打分并注明证据

**目标：** 把判断与事实分开  
**预计耗时：** 25 分钟 · **优先级：** 必须

**照着操作：**

- 1. 拿第3至4章的需求和竞品表做输入，不用AI凭空填写销量或需求。
- 2. 按需求证据/差异化/毛利/物流/合规/竞争6维打分
- 3. 注明不确定值
- 4. 将结果填写到「templates/market-research.csv」或对应记录表，并按“带证据列的评分表”逐项验收；每一条外部事实附原始网址/沟通记录，未知项保留待核查。

**可用资料：** [打开模板/入口](../templates/market-research.csv) · [详细操作](../playbooks/03-sku-score.md)

**完成标准：** 带证据列的评分表

**卡住怎么办：** 证据缺失记未知，不自动填高分

**证据性质：** 可复现的操作建议（非平台政策）。记录原始来源，不将教学演练当作成交证明。

### 05-03 选前3名做询价

**目标：** 把纸上利润变成报价  
**预计耗时：** 40 分钟 · **优先级：** 必须

**照着操作：**

- 1. 拿第3至4章的需求和竞品表做输入，不用AI凭空填写销量或需求。
- 2. 每个候选找至少两家独立供应商，拿样品价与物流约束
- 3. 将结果填写到「templates/market-research.csv」或对应记录表，并按“6份可追溯报价或沟通记录”逐项验收；每一条外部事实附原始网址/沟通记录，未知项保留待核查。

**可用资料：** [打开模板/入口](../templates/market-research.csv) · [详细操作](../playbooks/03-sku-score.md)

**完成标准：** 6份可追溯报价或沟通记录

**卡住怎么办：** 找不到供应商就降低优先级

**证据性质：** 可复现的操作建议（非平台政策）。记录原始来源，不将教学演练当作成交证明。

### 05-04 明确淘汰条件

**目标：** 提前拒绝不良商品  
**预计耗时：** 25 分钟 · **优先级：** 必须

**照着操作：**

- 1. 拿第3至4章的需求和竞品表做输入，不用AI凭空填写销量或需求。
- 2. 规定交付周期、单笔贡献、售后复杂性、采购起订量上限
- 3. 将结果填写到「templates/market-research.csv」或对应记录表，并按“选品Go/No-Go决定”逐项验收；每一条外部事实附原始网址/沟通记录，未知项保留待核查。

**可用资料：** [打开模板/入口](../templates/market-research.csv) · [详细操作](../playbooks/03-sku-score.md)

**完成标准：** 选品Go/No-Go决定

**卡住怎么办：** 没拿到总成本不允许进入上架步骤

**证据性质：** 可复现的操作建议（非平台政策）。记录原始来源，不将教学演练当作成交证明。



## 一次完整验证如何留证据

| 字段 | 应填写内容 |
|---|---|
| 本次要判断的问题 | 一句话，能作出 Go / Pivot / Stop 决定 |
| 目标客户和市场 | 国家、细分人群、购买场景 |
| 原始证据 | 客户回复、报价、订单或官方规则原文 |
| 假设成本 | 逐项列出，不能当作供应商报价 |
| 实际成本 | 结算截图/账单，有日期与币种 |
| AI 做了什么 | 输入、提示词、输出、人工复核点 |
| 结果与下一次动作 | 继续 / 调整 / 暂停，负责人和截止时间 |

## 常见失败与处理

**没有支付资格：** 换可用的合规平台或服务路径，不购买非正规账号。  
**看到热门商品：** 先证明自己能以合理成本获取客户，而不是先囤货。  
**利润为正但现金不够：** 缩小样品/试单规模，记录首批资金与到账周期。  
**AI 输出与商品不符：** 删除不实宣传、重新核对供应商文件和样品。  
**样本太小：** 保留未知，不把一次接单外推成稳定增长。
