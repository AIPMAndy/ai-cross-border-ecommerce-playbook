# 第一批 100 个真实访客｜可执行获客实验

**100 是实验设计的观察目标，不是已达到的数据，也不是转化率承诺。**

## 目的

比起空转广告账户，先证明有人愿意访问一个能实际履约的商品页，并区分点击、咨询和付款。

## 具体实施

1. 明确一个目标国家、一个使用场景和一个商品。
2. 确保落地页真实：材质、价格、含税费/运费、交付日期与退款政策。
3. 做 3 条不同角度的真实商品内容：问题、实际使用、送礼场景。
4. 给每条内容独立 URL 参数和内容编号，不虚构真实流量。
5. 先用自然渠道观察；如果决定付费，要设置每日与总预算上限。
6. 在 [漏斗表](../templates/visitor-funnel.csv) 记录用户来源、真实访问、加购、付款数。
7. 完成测试后记录客户最常提的问题，判断继续/调整/停止。

## 验收

- [ ] 追踪 URL 实际可访问。
- [ ] 确保测试账号订单不会被误算成真实收入。
- [ ] 有真实流量或明确记录流量为 0 的复盘。
- [ ] 已分开记录浏览、加购、付款、实际结算。
- [ ] 已记录下一实验唯一变化。

**结果为零时**也算完成一次有证据的验证，不允许购买假数据。
