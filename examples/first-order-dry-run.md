# 从零到第一单｜全过程干跑（虚构教学演练）

**没有真实交易，买家、订单、成本均为教学假设。** 本例教你搜集实际证据，不把模拟结果说成真实成交。

## 场景

目标市场：美国；品类：原创宠物主题帆布包；销售假设价格 $39。主体、平台资格、收款通道、商品合规和物流都需要实际验证。

| 阶段 | 操作 | 验收凭据 | 当前状态 |
|---|---|---|---|
| 市场 | 30 条原始评论、5 次用户访谈 | URL / 访谈记录 | 待执行 |
| 竞品 | 10 个可购买竞品 | 真实价格、物流、评价 | 待执行 |
| 供应商 | 至少两家询价与样品 | 报价书、规格和样品照 | 待执行 |
| 收款 | 合法账户和实际结算测试 | 后台确认及打款记录 | 未验证（阻塞） |
| 商品页 | 真实规格、图片和售后说明 | 草稿与事实核对 | 可先制作草稿 |
| 获客 | 三条内容与带参数链接 | 可追踪实际访问 | 未执行 |
| 订单 | 用户付款、履约、实际结算 | 脱敏订单与对账 | 0 笔 |
| 复盘 | 贡献利润和现金压力 | 实际账单和计算记录 | 当前只可做假设模型 |

## 模拟报价（不是利润事实）

| 项目 | USD/单（教学假设） |
|---|---:|
| 售价 | 39.00 |
| 商品 | -11.00 |
| 国际/末端配送 | -8.00 |
| 进口关税及税费准备 | -1.50 |
| 假设平台费 8% | -3.12 |
| 假设支付费 3.2% + 0.30 | -1.55 |
| 退款损失储备 5% | -1.95 |
| 汇兑费用 | -0.50 |
| 广告获客 | -7.00 |
| **广告后订单贡献** | **+4.38** |

如果广告费每单增加 $5，则单笔贡献为 **−$0.62**。这一结果不包括固定费用、企业所得税、人力和全部现金资金占用。

使用 [利润计算器](../index.html#calculator)、[现金计算器](../index.html#cashflow) 和 [样本 JSON](../tools/sample-quote.json) 修改假设。

## 成为真实第一单的必要条件

- [ ] 官方资格核验通过且合法付款测试完成。
- [ ] 保存买家真实付款凭据（脱敏）。
- [ ] 保存履约交付和跟踪记录（脱敏）。
- [ ] 区分买家付款与平台向商家实际结算。
- [ ] 使用真实发票和账单重算贡献。
- [ ] 把实际订单和现金记录写入 [第一单证据表](../templates/first-order-evidence.csv)。
